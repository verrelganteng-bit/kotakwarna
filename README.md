1. apa itu javascript dan kegunaannya?
javascript adalah salah satu bahasa pemrograman dan salah satu kegunaannya adalah untuk merubah elemen web dan memodifikasi tampilan web
menjadi lebih menarik dan menjadi lebih interaktif.
2. apa itu jquery dan kegunannya?
jquery adalah library dari javascript itu sendiri untuk memudahkan menulis kode javascript, mengedit HTML, merubah CSS.
3. Perbedaan javascript dan jquery
   JavaScript merupakan bahasa pemrograman yang dapat digunakan secara langsung di browser, sedangkan jQuery merupakan library yang dibangun menggunakan JavaScript untuk mempermudah pengembangan halaman web.
